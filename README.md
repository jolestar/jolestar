## Representative Open Source Projects

These projects roughly trace my path across cloud infrastructure, Move/blockchain systems, and, more recently, agent tooling.

1. [holon-run/webmcp-bridge](https://github.com/holon-run/webmcp-bridge) — Core Contributor, 2026–present  
   A bridge that lets local MCP clients use browser-native WebMCP tools through Playwright, with native and adapter-backed execution paths.
2. [holon-run/uxc](https://github.com/holon-run/uxc) — Creator / Core Contributor, 2026–present  
   A universal API calling CLI that gives agents one URL-first interface across OpenAPI, gRPC, GraphQL, MCP, JSON-RPC, and subscriptions.
3. [holon-run/holon](https://github.com/holon-run/holon) — Core Contributor, 2025–present  
   A headless coding-agent runner that turns GitHub issues into PR-ready patches and summaries for local or CI workflows.
4. [nuwa-protocol/x402-exec](https://github.com/nuwa-protocol/x402-exec) — Core Contributor, 2025–2026  
   A programmable settlement framework for the x402 protocol, combining payment verification, hook-based business logic, and facilitator incentives in atomic transactions.
5. [nuwa-protocol/nuwa](https://github.com/nuwa-protocol/nuwa) — Core Contributor, 2025–present  
   An AI protocol and product monorepo focused on programmable agents, execution, and protocol-level coordination.
6. [rooch-network/rooch](https://github.com/rooch-network/rooch) — Core Contributor, 2023–present  
   A Move-based execution environment for the Bitcoin ecosystem, with work spanning state, storage, replay, and Bitcoin-related infrastructure.
7. [move-language/move](https://github.com/move-language/move) — Contributor, 2022–2023  
   The reference implementation of the Move language and toolchain, where I contributed to VM compatibility, formatting, testing, and type-related tooling.
8. [starcoinorg/starcoin](https://github.com/starcoinorg/starcoin) — Core Contributor, 2020–2022  
   A Move smart contract blockchain, where I contributed across releases, Move upgrades, tooling, package management, and CLI/runtime workflows.
9. [jolestar/gomoku-wasm](https://github.com/jolestar/gomoku-wasm) — Creator, 2019–present  
   A Gomoku game built with WebAssembly, representing one of my more complete experimental projects outside infrastructure and blockchain tooling.
10. [jolestar/kubernetes-complete-course](https://github.com/jolestar/kubernetes-complete-course) — Creator, 2017–present  
   A comprehensive Chinese-language Kubernetes course repository that has been widely referenced by developers learning the ecosystem.
11. [jolestar/docker-proxy](https://github.com/jolestar/docker-proxy) — Creator, 2017–present  
   A Dockerized proxy stack built from Squid and Stunnel, created as a practical infrastructure utility project.
12. [yunify/metad](https://github.com/yunify/metad) — Contributor, 2016–2017  
   A metadata server project from the early cloud infrastructure stage, where I contributed features around metadata access rules, version waiting, and benchmark tooling.
13. [jolestar/go-commons-pool](https://github.com/jolestar/go-commons-pool) — Creator, 2015–present  
   A generic object-pool library for Go and one of my longest-running open-source projects.
14. [jolestar/jmeter-mongodb-plugin](https://github.com/jolestar/jmeter-mongodb-plugin) — Creator, 2013–present  
   A JMeter plugin for persisting sampler JSON responses into MongoDB, representing my earlier Java tooling work.
